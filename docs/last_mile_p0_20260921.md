# Minimal P0 验收说明

**2026-09-21｜通过，结束本次任务。未启动 P1/P2。**

按用户最终确认的简化范围，固定试点、禁用自动 repair，并验证同一快照下 A/B 检查不污染后续状态。这不是 last-mile 效果或抓取成功率实验。

## 验收结果

| 项目 | 实际结果 |
|---|---|
| 试点 | 10 条，5 houses：388、191、165、269、457；每 house 2 条 |
| A → restore → A | 10/10 通过，包含控制器、任务/传感器缓存和 RNG 扰动后的恢复 |
| B → restore → A 对比直接 A | 10/10 通过；B 为底盘平移 0.1 m 的工程测试位姿 |
| 积分状态最大恢复误差 | 0；未放宽原数值容差 |
| 自动 base repair | 显式关闭；不执行跨机器人替换 |
| 单元回归 | 13 项通过 |
| 数据复现 | 两次构建的清单、顺序、seed 和 benchmark 内容一致；源 JSON 未变 |
| 正式集 | 100 条、100 houses，与试点 house 隔离；仅冻结，未运行仿真 |

Minimal P0 每条只做一轮核心恢复与顺序污染检查，**未把原完整协议的 10 轮恢复、20 控制步重放列为本轮验收条件**。有效运行协议见 [inputs.json](../eval_output/last_mile/p0_20260921/validation_minimal/inputs.json)；根目录 config 保留早先冻结记录，实际简化参数以该 inputs 中的 `validation_protocol` 为准。
